# FbClone

A Facebook UI clone built with React and Tailwind CSS.

This project recreates the core Facebook interface — including the header, stories, post feed, sidebar, and widgets — as a frontend demo.

## Features

- **Responsive Header** with search bar, navigation icons (Home, Watch, Marketplace, Groups, etc.), and user profile menu
- **Stories** section
- **Post Creation** input box
- **News Feed** with posts showing images, captions, timestamps, and interaction buttons (Like, Comment, Share)
- **Left Sidebar** (shortcuts / menu)
- **Right Widgets** panel
- Styled with **Tailwind CSS** and **Heroicons**

## Tech Stack

- **React** 18
- **Tailwind CSS** 3
- **Heroicons**
- **Headless UI**
- Create React App
